## 操作手册（SKILL.md 正文）

```markdown
# 在线表格和文档

在线表格的格子是画在画布（canvas）上的，browser_snapshot 里只看得到工具栏、菜单和名称框，看不到格子，也点不中某一格。
所以：**读写数据一律走剪贴板，不要逐格点、逐格输入。**

## 准备
1. 打开文档地址，先拿一次快照（depth 4～6），确认已经登录、打开的是对的文件和工作表（底部的工作表标签）。
2. 找到「名称框」（也叫定位框，通常在公式栏左边，快照里是一个 textbox，里面写着当前格子，例如 A1）。后面读写都靠它定位。

## 读一块数据
1. 点名称框，输入区域（例如 A1:H200），回车：browser_type 带 submit: true。
2. browser_clipboard_read，copy: true（会先按 Ctrl+C）。
3. 返回的是按行列整理好的表格，每行开头是行号（第 1 行 = 选区的第一行）。太长会分段：按提示的 offset 接着读；完整内容也存成了文件，可以用 file.read 读。
4. 读回「剪贴板是空的」：多半是没选中（名称框没生效、焦点不在表格上），重新定位再试。

## 写一块数据
1. 先读一遍要写的区域，确认是空的或者就是要覆盖的（粘贴会直接覆盖原有内容）。
2. 点名称框，输入起始格（例如 A2），回车。
3. browser_clipboard_paste，table 填二维数组（每个元素一行）。格子里可以有换行、制表符、引号。
4. 核对：名称框选中刚写的同样大小的区域，browser_clipboard_read（copy: true），逐格和要写的比对；不一致的再改。
5. 注意：
   - 以 = 开头的文字会被当成公式；要原样写进去，前面加一个英文单引号 '（待实测：各家是否都认）。
   - 长数字（订单号、手机号）、前导零（00123）、像日期的文字（3-5）会被自动转格式；同样加 ' 或者先把那一列设成「文本」格式（待实测）。
   - 粘贴进去的是纯文字，不带字体、颜色、边框。

## 往文档、表格里贴图
1. 在图片所在的网页上拿快照，browser_copy_image（element 写图片描述，target 填图片的 ref）。它取的是原图，存成了这次运行的文件，输出里有文件 id。
2. 切回文档的标签页（browser_tabs select），点到要放图的位置（文档里点到那一段；表格里用名称框定位到格子）。
3. browser_clipboard_paste，fileId 填上一步的文件 id。
4. 确认贴上了：拿快照找新出现的图片对象；任务开了「允许看画面」的，用 browser_look 看一眼。
5. 贴不进（有的平台不收剪贴板里的图）：用网页的「插入 → 图片 → 本地上传」，弹出选文件框后 browser_file_upload，fileIds 填那个文件 id。

## 允许看画面时
- browser_look 截当前画面给你看，截图里的坐标可以直接用于 browser_mouse_click_xy。
- 只在快照解决不了时用：找不到菜单、确认粘贴结果、要点画布上的某个位置。每看一次多一张图的费用，别每步都看。

## 不要
- 不要逐格点击、逐格输入（慢，而且点不准）。
- 不要用 Ctrl+A 全选整张表再复制（可能是几十万格）；用名称框选需要的区域。
- 不要在 http（非 https）页面上用剪贴板，Chrome 不允许。
```

## 各平台的差异

只写了有把握的；其余标「待实测」。验证过的请把结论补进上面的正文或单独一节。

### 腾讯文档（docs.qq.com）
- 表格：左上角公式栏左边有显示当前格子的框，可以输入区域跳转（待实测：快照里的名字、回车后是否选中整块）。
- Ctrl+C / Ctrl+V 复制粘贴表格内容（待实测：粘贴 TSV 是否按格拆开、换行格子是否保持在一格里）。
- 贴图：「插入 → 图片」可以本地上传（待实测：剪贴板里的图能否直接 Ctrl+V 贴进表格 / 文档）。

### 飞书（feishu.cn / larksuite.com）
- 电子表格：公式栏左边有名称框（待实测：快照里的名字）。
- 复制粘贴表格内容、剪贴板贴图（待实测）。
- 飞书文档里的表格是文档块，不是电子表格，名称框那套不适用（待实测：要不要先点进表格块再粘贴）。

### WPS 云文档（kdocs.cn）
- 表格界面和 Excel 接近，公式栏左边有名称框（待实测）。
- 复制粘贴、贴图（待实测）。

### Google Sheets（docs.google.com/spreadsheets）
- 左上角（公式栏 fx 左边）是名称框，输入 A1:H200 回车会选中这块区域。
- 粘贴制表符分隔的文字会按格拆开，多行对应多行。
- 贴图：「插入 → 图片」有「在单元格内插入图片」「在单元格上方插入图片」，都可以上传本地文件（待实测：剪贴板里的图 Ctrl+V 直接贴的效果）。
- 筛选、隐藏行状态下复制得到哪些行（待实测）。
